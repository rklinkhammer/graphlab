# Two-stream TCP telemetry fixture

Build against an installed LabSupport 1.4.0 SDK using this directory's CMake project. Use the existing Dockerfile with an explicitly pinned compatible base image; never resolve a mutable base tag implicitly.

The fixture retains the UDP node aggregate and opts into the SDK's bounded, gated two-stream TCP echo service. Declare application edges `alpha` and `beta`, each targeting the topology node hosting this fixture. An uninstrumented app-b built with the same SDK can explicitly send `control probe-alpha IP` and `control probe-beta IP`. No traffic is generated by collection.

See [application-edge telemetry](../../docs/application-edge-telemetry.md) for wire format, report ownership, reconnect and latency definitions, exclusions and limits. The fixture does not implement source pause/resume or message/capture correlation.
